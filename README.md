# Swear Words Czech - Antiswear plugin CZ

Zde je vypsaná většina českých a některé zahraniční nadávky, které se v česku používají.
<br><br>
### Návod na stažení:

1. Zkopíruj, nebo stáhni soubor swearwords.txt
2. Ulož ho do configu svého pluginu, každý to má jinak (Někdy ho musíš vložit přímo do configu pluginu, pokud tomu tak je, prostě jenom zkopíruj obsah souboru swearwords.txt do configu svého pluginu).
3. Užívej

<br><br>

PS:  Jsou zde i slova s gramatickými chybami a překlepy, pro pluginy, které neumí poznat a filtrovat podobné slova.
